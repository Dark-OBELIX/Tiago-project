Commande pour récupérer l'audio

Pour récupérer l'audio de la pieuvre dans le Docker, il faut créer le conteneur comme suit :

docker run -it \
  -d \
  -u user \
  -e DISPLAY=$DISPLAY \
  --network host \
  --privileged \
  -v /tmp/.X11-unix/:/tmp/.X11-unix/ \
  -v $HOME/.config/pulse:/root/.config/pulse \
  --device /dev/snd \
  --name="tiago-real-audio-usb" \
  docker_tiagocesi_image_full \
  bash


Il faudra ensuite installer la bibliothèque audio :

sudo apt-get install -y alsa-utils


On peut vérifier que le micro est bien détecté par le Docker avec la commande :

arecord -l


Si le périphérique USB Audio n'est pas trouvé sous hw:2,0, il faudra adapter la commande en fonction du périphérique correct (par exemple, hw:0,0 si nécessaire).

Ensuite, pour enregistrer un fichier audio depuis le micro, on utilise la commande suivante :

sudo arecord -D hw:2,0 -f S16_LE -c 1 -r 48000 -t wav -d 10 test_usb_mic.wav


Et pour jouer l'enregistrement :

aplay /home/Tiago-project/audio/test_files/test_usb_mic.wav

Pour lancer le topic audio :

Pour l'écouter:
